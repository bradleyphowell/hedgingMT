What To Watch

Health Checks

Receive Latency

Watch Book Event to Local Receive and Trade Event to Local Receive for exchange-side or network drift.

Processing Drift

If queue depth grows above zero and Decision to Quote Post expands, the strategy loop is starting to fall behind incoming data.

Maker Path

Maker Upsert is local-only for now. Order Ack RTT stays as a placeholder until live Binance order placement and exchange acknowledgements are connected.

Clock Offset

The displayed latencies use Binance server-time offset estimation so event timestamps and local receive timestamps stay on the same clock basis.
